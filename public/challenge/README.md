# APPISTRY — THE HIDDEN KEY
### Official Mystery Hunt Challenge Repository

Welcome, Agent. You have retrieved the official codebase for **THE HIDDEN KEY**, organized by **APPISTRY — App Development Club, STC IIT Patna Hybrid**.

## Overview
A high-priority secret has been sealed inside an encrypted artifact within this archive (`artifact.enc.json`). Your objective is to discover the mystery passphrase, execute the unlock utility, extract the Hidden Key, and submit it on the official portal to claim the **FIRST BLOOD** bounty.

## Getting Started

### 1. Prerequisites
- Node.js (v18 or later)
- Terminal / VS Code

### 2. How to Run the Unlock Utility
Execute the following in this directory:

```bash
npm run unlock
# or directly:
node scripts/unlock.js
```

### 3. Submission
Once you unlock the secret keyword:
1. Copy the revealed keyword exactly.
2. Visit the submission portal: [http://localhost:3000/submit](http://localhost:3000/submit)
3. Enter your Name and IIT Patna Email (`@iitp.ac.in`).
4. Submit to claim your spot on the live leaderboard!

Good luck, developers!
